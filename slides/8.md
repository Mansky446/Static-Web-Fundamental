## Komentar

Dalam kode CSS kita bisa memberikan komentar dengan:

```css
/*
    Ini komntar banyak baris di CSS
*/
```

## Atribut Class dan Id

Pada elemen HTML ada atribut khusus yang digunakan untuk keperluan memilih elemen spesifik agar elemen tersebut bisa interaktif maupun memiliki tampilan yang sesuai.

- Atribut `id` merupakan atribut bernilai yang nilainya harus unik di satu file HTML tersebut.
- Atribut `class` merupakan atribut bernilai yang nilainya boleh tidak unik (bisa muncul di banyak elemen) di satu file HTML tersebut.
- Kedua atribut ini memiliki scope "satu file" sehingga file lain tidak akan terpengaruh.

## Pemilihan Elemen

Pada kode CSS kita bisa memilih elemen spesifik berdasarkan:

- Nama elemen.
- Atribut `id` atau `class`.
- Atribut spesifik.
- Kombinasi selector spesifik.
- Status elemen (pseudo-class).
- Bagian dari elemen (pseudo-element).

Bila kita menggunakan CSS eksternal, maka selector CSS akan menyesuaikan dengan file HTML mana yang menggunakan CSS eksternal tersebut.
Sehingga memungkinkan untuk style di file CSS yang berbeda dipakai oleh sebuah atau sekelompok elemen di satu file HTML yang menggunakan file CSS tersebut (templating).

## Selector Dasar

Memilih semua elemen dengan simbol `*`:

```css
* {
    margin: 0;
    padding: 0;
}
```

Memilih elemen berdasarkan nama elemennya dengan:

```css
div {
    color: whitesmoke;
    background-color: black;
}
```

Berdasarkan atribut `id` dengan simbol `#` dan `class` dengan simbol `.`:

```css
#main-header { /* ini untuk selector id */
    background-color: red;
}

.container { /* ini untuk selector class */
    background-color: gold;
}
```

## Atribut Spesifik

Memilih elemen dengan atribut spesifik bisa dilakukan dengan `[nama-atribut="nilai-atribut"]`.
Simbol `=` dan nilai atribut adalah opsional dengan makna:

- `[type]`: Semua elemen yang memiliki atribut `type`.
- `[type="text"]`: Semua elemen yang memiliki atribut `type` dan nilainya harus tepat `text`.
- `[title~="flower"]`: Semua elemen yang memiliki atribut `title` dan harus ada kata tepat `flower` pada nilainya (word boundary).
- `[class|="desc"]`: Semua elemen yang memiliki atribut `class` dan nilainya harus `desc` atau diawali dengan `desc-`.
- `[href^="http"]`: Semua elemen yang memiliki atribut `href` dan nilainya harus diawali dengan `http`.
- `[src$=".png"]`: Semua elemen yang memiliki atribut `src` dan nilainya harus diakhiri dengan `.png`.
- `[class*="container"]`: Semua elemen yang memiliki atribut `class` dan harus ada kata `container` pada nilainya.

Contoh panggunaan:

```css
[type] {
    border: 1px solid gray;
}

[type="text"] {
    color: darkblue;
}

[title~="flower"] {
    color: crimson;
    background-color: gainsboro;
}

[class|="desc"] {
    color: brown;
}

[href^="http"] {
    border: 1px dotted black;
}

[src$=".png"] {
    border: 1px solid blue;
}

[class*="container"]:hover {
    top: 2px;
    left: 2px;
}
```

## Kombinasi Selector Spesifik

Adapun kombinasi antar selector bisa kita ubah dengan beberapa operator seperti:

- Hubungan antar selector:
    - tanpa spasi: Semua selector harus tepenuhi (and).
    - `,`: Salah satu selector akan aktif (or).
- Hubungan child dan parent:
    - ` ` (spasi): Selector setelah spasi adalah selector child dan sebelum spasi adalah selector parent. Selector parent dan child harus tepenuhi. Selector child harus menjadi child dari selector parent. Style akan ditetapkan hanya pada selector child.
    - `>`: Selector setelah spasi adalah selector child dan sebelum spasi adalah selector parent. Selector parent dan child harus tepenuhi. Selector child harus tepat menjadi child dari selector parent. Style akan ditetapkan hanya pada selector child.
- Hubungan tetangga:
    - `+`: Selector setelah `+` adalah selector tetangga setelah dan sebelum `+` adalah selector tetangga sebelum. Yang berarti selector sebelum dan setelah harus terpenuhi. Selector sebelum harus berada sebelum selector setelah. Style akan ditetapkan hanya pada selector setelah.
    - `~`: Selector setelah `~` adalah selector tetangga setelah dan sebelum `~` adalah selector tetangga sebelum. Yang berarti selector sebelum dan setelah harus terpenuhi. Selector sebelum harus tepat berada sebelum selector setelah. Style akan ditetapkan hanya pada selector setelah.

Berikut bobot operator-operator itu:

- tanpa spasi, ` ` (spasi), `>`, `+`, `~`, `:`, `::`: Bobot tertinggi dengan sifat left association.
- `,`: Bobot terendah dengan sifat left association.

Dengan begitu, `,` akan di evaluasi lebih akhir dibanding operator lainnya.
Dan karena semuanya bersifat left association maka bila operator bertemu dengan operator lain yang bobotnya sama, akan langsung di evaluasi dari kiri ke kanan.

Contoh panggunaan:

```css
div.container > p, span.tag {
    /* Style disini akan diterapkan pada:
        - Elemen p yang menjadi child dari div yang memiliki atribut class bernilai "container"
        - Atau pada elemen span yang memiliki atribut class bernilai "tag" */
    color: red;
}
```

## Status Elemen

Kita dapat memberi style pada elemen dengan status tertentu dengan pseudo-class.
Format untuk pseudo-class adalah `:nama-pseudo-class`.
Adapun nama-nama dari pseudo-class adalah sebagai berikut:

- `root`: Elemen root document.
- `active`: Elemen yang berstatus sedang aktif (ditekan).
- `hover`: Kursor sedang berada diatas elemen tersebut.
- `link`: Link yang belum dikunjungi/dibuka.
- `visited`: Link yang sudah dikunjungi/dibuka.
- `empty`: Elemen yang tidak memiliki child.
- `enabled`: Elemen-elemen input yang bisa diisi.
- `disabled`: Elemen-elemen input yang tidak bisa diisi.
- `checked`: Elemen-elemen input yang sedang terceklis seperti input radio atau input checkbox
- `focus`: Elemen yang sedang di fokus, biasanya untuk elemen-elemen input saat sedang diisi.
- `invalid`: Elemen-elemen input yang diisi oleh data yang tidak valid.
- `valid`: Elemen-elemen input yang diisi oleh data yang valid.
- `user-invalid`: Elemen-elemen input yang diisi oleh data yang tidak valid dan hanya terupdate saat input sudah tidak lagi terfokus (user selesai mengisi data atau memindahkan fokus ke elemen lain).
- `user-valid`: lemen-elemen input yang diisi oleh data yang valid dan hanya terupdate saat input sudah tidak lagi terfokus.
- `optional`: Elemen-elemen input yang opsional (tidak memiliki atribut `required`).
- `required`: Elemen-elemen input yang harus diisi (memiliki atribut `required`).
- `readonly`: Elemen-elemen input yang berstatus mode baca.
- `placeholder-shown`: Elemen-elemen input yang sedang menampilkan placeholder (tidak diisi data).
- `first-child`: Elemen yang menjadi child pertama.
- `first-of-type`: Elemen yang menjadi child pertama dengan nama elemen tersebut.
- `last-child`: Elemen yang menjadi child terakhir.
- `last-of-type`: Elemen yang menjadi child terakhir dengan nama elemen tersebut.
- `nth-child(n)`: Elemen yang menjadi child ke `n` (dihitung dari awal).
- `nth-of-type(n)`: Elemen yang menjadi child ke `n` dengan nama elemen tersebut (dihitung dari awal).
- `nth-last-child(n)`: Elemen yang menjadi child ke `n` (dihitung dari akhir).
- `nth-last-of-type(n)`: Elemen yang menjadi child ke `n` dengan nama elemen tersebut (dihitung dari akhir).
- `only-child`: Elemen yang menjadi satu-satunya child.
- `only-of-type`: Elemen yang menjadi satu-satunya child dengan nama elemen tersebut.
- `not(s)`: Untuk membalikkan selector yang berarti style kan diterapkan ke selain dari selector `s`.

Di `not(s)`, `s` adalah selector.

Adapun nilai yang valid untuk `n` pada `nth-child(n)`, `nth-of-type(n)`, `nth-last-child(n)`, `nth-last-of-type(n)` adalah:

- Bilangan bulat spesifik untuk menunjuk elemen ke-`n`.
- `odd` untuk setiap `n` yang ganjil.
- `even` untuk setiap `n` yang genap.

Contoh panggunaan:

```css
div.container > button:nth-of-type(odd):hover {
    background-color: papayawhip;
}

div.container > button:nth-of-type(3):active {
    background-color: gainsboro;
}

li:not([class]) {
    font-weight: bolder;
}
```

## Bagian Dari Elemen

Kita dapat memberi style pada bagian tertentu di sebuah elemen dengan pseudo-element. Format untuk pseudo-element adalah `::nama-pseudo-element`.
Pseudo-elemen ini harus berada di paling ujung kanan (dievaluasi terakhir) diantara operator-operator yang memiliki bobot tinggi.
Adapun nama-nama dari pseudo-element adalah sebagai berikut:

- `selection`: Teks yang di select oleh user pada elemen.
- `placeholder`: Teks placeholder pada elemen.
- `marker`: Penanda pada elemen `<li>`.
- `file-selector-button`: Tombol pada `<input type="file">`.
- `first-letter`: Huruf pertama pada elemen.
- `first-line`: Baris pertama pada elemen.
- `before`: Bagian awal dari elemen (seperti menjadi child pertama).
- `after`: Bagian akhir dari elemen (seperti menjadi child terakhir).

`first-letter` dan `first-line` hanya berlaku untuk elemen yang memiliki properti display bernilai `block` atau `inline-block`.

Pada `before` dan `after`, properti `content` adalah wajib.
Bila tidak ingin menambahkan `content`, maka nilai dari properti `content` bisa berupa string kosong `""` atau `none`.

Contoh panggunaan:

```css
input::placeholder {
    color: darkblue;
    opacity: 0.2;
}

span.tag::before {
    content: "<";
}

span.tag::after {
    content: ">";
}
```
