## Apa Itu CSS

- CSS merupakan singkatan dari Cascading Style Sheets.
- CSS menjelaskan bagaimana caara untuk menggambar elemen HTML.
- CSS dapat mengontrol style antar halaman (file HTML yang berbeda).
- HTML merupakan tempat untuk kita mendefinisikan elemen-elemen dan kontennya sedangkan CSS mendefinisikan bagaimana elemen tersebut akan digambar ke layar oleh web.

## Struktur Dasar CSS

```css
selector {
    nama-properti: nilai-properti;
}
```

Penjelasan:

- `selector`: Elemen HTML apa yang ingin diberikan style.
- `{` dan `}`: Merupakan pembuka dan penutup style group.
- `properti`: Merupakan properti apa yang ingin berubah (diberi style).
- `nilai-properti`: Nilai dari propertinya.

## Letak Kode CSS

Kode CSS bisa kita letakkan diantara sebagai:

### CSS Eksternal

Kode CSS yang terletak di file yang berbeda dengan file HTML nya.
Lalu kita hubungkan file CSS tersebut dengan file HTML-nya dengan:

```html
<link rel="stylesheet" href="style.css">
```

### CSS Internal

Kode CSS yang terletak didalam file HTML yang sama.
Kita harus meletakkan kode CSS tersebut didalam elemen sebagai konten dari elemen tersebut:

```html
<style></style>
```

### CSS Inline

Kode CSS yang terletak di dalam elemen HTML yang ingin diberi style-nya.
Kode CSS yang kita letakkan sebagai nilai dari atribut `style` merupakan CSS inline.
CSS inline tidak boleh memakai selector karena sudah spesifik kode CSS tersebut untuk elemen apa.

```html
<p style="font-size: 24pt;">Ini paragraf.</p>
```

## Properti dan Nilai-nya

### Properti CSS

- Properti di CSS banyak namanya.
- Nama properti di CSS tidak case-sensitive.
- Bila nama properti tersiri dari lebih dari 2 kata maka menggunakan `-` sebagai separatornya, bukan spasi.

### Nilai Properti CSS

- Nilai properti dapat berupa identifier, string, unit, warna ataupun sekumpulan nilai.
- Identifier sebagai nilai properti berbentuk sama dengan nama properti, yaiu tidak case-sensitive dan menggunakan `-` sebagai separator kata.
- String sebagai nilai properti berbentuk `'Ini String'` atau `"Ini String"`.
- Unit sebagai nilai properti di CSS dapat berbentuk:
  - `800`: Normal integer.
  - `12px`: Unit px.
  - `24pt`: Unit pt.
  - `0.2rem`: Unit rem.
  - `-1em`: Unit em.
  - `22.5%`: Unit persen.
  - `22s`: Unit detik.
  - `22ms`: Unit milidetik.
  - `2deg`: Unit derajat.
- Warna sebagai nilai properti di CSS dapat berbentuk:
  - `red`: Nama warna.
  - `rgb(255, 0, 0)`: Format rgb. Dengan nilai masing-masing 0-255.
  - `rgba(124, 0, 32, 0.3)`: Format rgba. Format rgb disertai dengan nilai 0-1 untuk alpha.
  - `hsl(100%, 20%, 0%)`: Format hsl. Dengan nilai masing-masing 0-100%.
  - `hsla(100%, 20%, 0%, 0.3)`: Format hsla. Format hsl disertai dengan nilai 0-1 atau 0-100% untuk alpha.
- Sekumpulan nilai merupakan kumpulan nilai dengan spasi atau `,` sebagai separatornya. Contoh nya adalah `border: 2px solid rgb(255, 0, 0);` yang berarti:
  - Properti dengan nama `border`.
  - Dengan nilainya bertipe sekumpulan nilai. Sekumpulan nilainya terdiri dari 3 nilai yaitu:
    - Unit px `2px`.
    - Identifier `solid`.
    - Warna `rgb(255, 0, 0)`.

## Styling Text

Kita bisa mengubah tampilan paragraf dengan CSS inline:

```html
<p style="font-size: 16pt; color: red; font-family: Arial; font-weight: 800; font-style: italic;">Ini paragraf bergaya.</p>
```

Atau menggaunakan CSS internal seperti dibawah ini.

Elemen `<style>`:

```html
<style>
    p {
        font-size: 16pt;
        color: red;
        font-family: Arial;
        font-weight: 800;
        font-style: italic;
    }
</style>
```

Elemen `<p>`:

```html
<p>Ini paragraf bergaya.</p>
```
