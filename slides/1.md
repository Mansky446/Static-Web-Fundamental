## Apa Itu HTML

- HTML merupakan singkatan dari Hyper Text Markup Language.
- HTML adalah standar markup language untuk halaman web.
- HTML terdiri dari banyak elemen-elemen.
- Setiap elemen di HTML memberi tahu web bentuk dari sebuah konten.
- Elemen HTML tidak case-sensitive.

## Sejarah HTML

- [1989] Tim Berners-Lee menemukan WWW.
- [1991] Tim Berners-Lee menemukan HTML.
- [1993] Dave Raggett memulai diskusi tentang HTML+.
- [1995] HTML Working Group membuat HTML 2.0.
- [1997] HTML 3.2 direkomendasikan oleh W3C.
- [1999] HTML 4.01 direkomendasikan oleh W3C.
- [2000] XHTML 1.0 direkomendasikan oleh W3C.
- [2008] WHATWG memulai diskusi tentang HTML5.

- [2014] HTML 5.0 direkomendasikan oleh W3C.
- [2017] HTML 5.1 2nd direkomendasikan oleh W3C.
- [2014] HTML 5.2 direkomendasikan oleh W3C.

## Struktur HTML Dasar

```html
<!DOCTYPE html>
<html>
<head>
    <title>Judul Halaman</title>
</head>
<body>
    <h1>Ini Judul</h1>
    <p>Ini paragraf.</p>
</body>
</html>
```

Penjelasan:

- `<!DOCTYPE html>`: Sepotongan kode untuk mendeklarasikan bahwa file ini adalah file HTML yang mengikuti standar HTML terbaru.
- `<html>`: Root kontainer untuk semua elemen HTML.
- `<head>`: Elemen yang menjadi kontainer elemen-elemen informasi tentang HTML.
- `<body>`: Elemen yang menjadi kontainer semua elemen yang terlihat.
- `<title>`: Elemen yang mendefinisikan judul halaman.
- `<h1>`: Elemen yang menampilkan judul.
- `<p>`: Elemen yang menampilkan paragraf.

`<!DOCTYPE html>` merupakan sepotongan kode yang harus ada di setiap file HTML.
`<html>` merupakan elemen yang harus ada di setiap file HTML.

## Struktur Singkat Elemen HTML

Elemen dibagi menjadi 2 berdasarkan bentuknya, yaitu:

### Elemen Berisi

Elemen HTML yang memiliki konten.

Konten pada elemen berisi bisa berupa text, elemen ataupun keduanya.

```html
<namaelemen>Isi elemen...</namaelemen>
```

### Elemen Tidak Berisi

Elemen yang tidak memiliki konten.

```html
<namaelemen>
```

Atau:

```html
<namaelemen/>
```
