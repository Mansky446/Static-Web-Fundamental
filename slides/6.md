## List

Di HTML ada elemen yang digunakan untuk membuat list yaitu:

- `<ul>` untuk list yang tidak memiliki urutan.
- `<ol>` untuk list yang memiliki urutan.
- `<li>` untuk item dari list.

List yang tidak memiliki urutan biasanya menggunakan simbol bullet sebagai penanda itemnya:

```html
<ul>
    <li>Kopi</li>
    <li>Teh</li>
    <li>Susu</li>
</ul>
```

List yang memiliki urutan biasanya menggunakan angka atau huruf sebagai penanda itemnya:

```html
<ol>
    <li>Bangun pagi</li>
    <li>Bekerja</li>
    <li>Tidur</li>
</ol>
```

Adapun atribut yang bisa dipakai untuk `<ol>` adalah:

- `start` untuk mengubah nomor awal dari item list. Nilai yang diterima adalah desimal `start="3"`.
- `type` untuk mengubah simbol item list, nilai yang valid adalah:
  - `type="1"` untuk angka desimal.
  - `type="a"` untuk huruf kecil.
  - `type="A"` untuk huruf besar.
  - `type="i"` untuk angka romawi kecil.
  - `type="I"` untuk angka romawi besar.

Kita juga bisa membuat list multi-level, contohnya:

```html
<ol>
    <li>Bangun pagi</li>
    <li>Bekerja
        <ul>
            <li>Membuat laporan</li>
            <li>Rapat</li>
            <li>Menggambar desain</li>
        </ul>
    </li>
    <li>Tidur</li>
</ol>
```

## List Deskripsi

Di HTML juga ada element yang digunakan untuk membuat list deskripsi.
List yang itemnya punya deskripsi dengan:

- `<dl>` untuk list deskripsi.
- `<dt>` untuk item dari list.
- `<dd>` untuk deskripsi item dari list.

```html
<dl>
    <dt>Kopi</dt>
    <dd>Kopi penyegar mata</dd>
    <dd>Penyegar tangan juga</dd>
    <dt>Teh</dt>
    <dd>Teh beraroma wangi</dd>
</dl>
```

## Table

Kita bisa membuat tabel di HTML menggunakan:

- `<table>` untuk tabel (container baris dan kolom).
- `<tr>` untuk baris tabel.
- `<td>` untuk sel tabel.
- `<th>` untuk sel tabel sebagai judul.

```html
<table>
    <tr>
        <th>No.</th>
        <th>Nama</th>
        <th>Hobi</th>
        <th>Pekerjaan</th>
    </tr>
    <tr>
        <td>1.</td>
        <td>Ahmad</td>
        <td>Bermain bulutangkis</td>
        <td>Koki</td>
    </tr>
    <tr>
        <td>2.</td>
        <td>Amin</td>
        <td>-</td>
        <td>-</td>
    </tr>
    <tr>
        <td>3.</td>
        <td>Melisa</td>
        <td>Membaca buku</td>
        <td>Pelayan</td>
    </tr>
</table>
```

Adapun atribut elemen `<td>` dan `<th>` yang dapat mengubah layout dari tabel sepert:

- `colspan` mengambil seberapa banyak kolom yang dibutuhkan untuk sel tersebut.
- `rowspan` mengambil seberapa banyak baris yang dibutuhkan untuk sel tersebut.

Di dalam tabel kita bisa memberi bagian-bagian table menjadi:

- `<thead>` tabel bagian atas (header).
- `<tbody>` tabel bagian isi (body).
- `<tfoot>` tabel bagian bawah (footer).

```html
<table>
    <thead>
        <tr>
            <th colspan="3">Dokumen</th>
        </tr>
        <tr>
            <td>Nama</td>
            <td>Penanggung Jawab</td>
            <td>Status</td>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Perencanaan</td>
            <td rowspan="2">Yoga</td>
            <td>Terpenuhi</td>
        </tr>
        <tr>
            <td>Tabel Anggaran</td>
            <td>Terpenuhi</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="3">Total: 2</td>
        </tr>
    </tfoot>
</table>
```

## Properti CSS List

Adapun properti CSS khusus untuk list:

- `list-style-type` mengubah simbol item list.
- `list-style-position` mengubah posisi simbol item list.

Nilai properti `list-style-type` yang sering digunakan untuk elemen `<ol>`:

- `list-style-type: lower-alpha;`
- `list-style-type: upper-alpha;`
- `list-style-type: lower-roman;`
- `list-style-type: upper-roman;`
- `list-style-type: decimal;`
- `list-style-type: decimal-leading-zero;`

Nilai properti `list-style-type` yang sering digunakan untuk elemen `<ul>`:

- `list-style-type: circle;`
- `list-style-type: disc;`
- `list-style-type: square;`

Properti `list-style-position` hanya menerima:

- `list-style-position: inside;`
- `list-style-position: outside;`

## Properti CSS Table

Propert `table-collapse` digunakan untuk mengubah sifat border dari sel dan tabel:

- `table-collapse: separate;` untuk border sel dan tabel terpisah.
- `table-collapse: collapse;` untuk border sel dan tabel menyatu.
