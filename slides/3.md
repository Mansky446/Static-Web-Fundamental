## Elemen Judul

```html
<h1>Judul Utama</h1>
<h2>Judul Pembahasan</h2>
<h3>Subjudul Pembahasan</h3>
<h4>Subjudul Pembahasan</h4>
<h5>Subjudul Pembahasan</h5>
<h6>Subjudul Pembahasan</h6>
```

Elemen HTML yang digunakan untuk menampilkan judul dan subjudul antara lain:

- `<h1>`: Judul yang paling besar, biasanya hanya ada satu di satu file html.
- `<h2>`: Judul untuk sebuah pembahasan
- `<h3>` - `<h6>`: Subjudul untuk sebuah pembahasan.

## Elemen Paragraf

Elemen HTML yang digunakan untuk menampilkan paragraf atau teks biasa bernama `<p>`.

## Elemen Formatting Teks

Elemen HTML yang digunakan untuk mengubah bentuk teks yang biasanya ada didalam tag-tag teks, yaitu:

- `<b>`: Untuk menebalkan teks.

  ```html
  <p>Ini teks <b>tebal</b></p>
  ```

- `<strong>`: Sama seperti `<b>`, sama-sama menebalkan teks. Biasanya untuk bagian teks yang penting.

  ```html
  <p>Ini teks <strong>penting!</strong></p>
  ```

- `<i>`: Untuk teks miring (italic).

  ```html
  <p>Ini teks <i>miring</i></p>
  ```

- `<em>`: Sama seperti `<i>`, sama-sama me-miringkan teks. Biasanya untuk bagian teks yang diberi penekanan.

  ```html
  <p>Ini teks <em>yang diberi penekanan</em></p>
  ```

- `<small>`: Untuk mengecilkan teks.

  ```html
  <p>Ini teks <small>kecil</small></p>
  ```

- `<mark>`: Untuk menampilkan teks yang ditandai.

  ```html
  <p>Ini teks <mark>yang ditandai</mark></p>
  ```

- `<del>`: Untuk menampilkan teks yang dihapus (style line-through).

  ```html
  <p>Ini teks <del>yang dihapus</del></p>
  ```

- `<ins>`: Untuk menampilkan teks yang digarisbawahi (underlined).

  ```html
  <p>Ini teks <ins>yang digarisbawahi</ins></p>
  ```

- `<sub>`: Untuk menampilkan teks subskrip.

  ```html
  <p>Ini teks <sub>subskrip</sub></p>
  ```

- `<sup>`: Untuk menampilkan teks superskrip.

  ```html
  <p>Ini teks <sup>superskrip</sup></p>
  ```

## Elemen Kuotasi

Elemen HTML yang digunakan untuk melakukan kuotasi (membuat kutipan), yaitu:

- `<code>`: Untuk menampilkan sepotongan kode.

  ```html
  <p>Ini merupakan <code>sepotongan kode</code></p>
  ```

- `<blockquote>`: Untuk menampilkan kutipan dari web lain.

  ```html
  <p>Dari Wikipedia tentang HTML:</p>
  <blockquote cite="https://id.wikipedia.org/wiki/HTML">
      HyperText Markup Language (HTML) adalah bahasa markah standar untuk dokumen yang dirancang untuk ditampilkan di peramban internet. Ini dapat dibantu oleh teknologi seperti Cascading Style Sheets (CSS) dan bahasa skrip lainnya seperti JavaScript, VBScript, dan PHP.
  </blockquote>
  ```

  Atribut `cite` digunakan untuk memberitahu web atau artikel mana kutipan itu berasal.

- `<q>`: Untuk memberi kutip pada teks.

  ```html
  <p>Ini teks <q>yang dikutip</q></p>
  ```

- `<abbr>`: Untuk menampilkan kata singkatan.

  ```html
  <p><abbr title="Hyper Text Markup Language">HTML</abbr> merupakan bahasa yang digunakan untuk menampilkan halaman web</p>
  ```

  Atribut `title` digunakan untuk memberi info saat elemen dihover.
  Di elemen `<abbr>`, atribut `title` digunakan untuk mendefinisikan kepanjangan dari kata singkatan tersebut.

- `<address>`: Untuk menampilkan informasi tantang penulis, artikel atau dokumen.

  ```html
  <address>
      Written by The Reaper.<br>
      Visit me at:<br>
      BestFuture.com<br>
      Illusion No. 32, South Dreamland<br>
      Dream Nation<br>
  </address>
  ```

- `<cite>`: Untuk menampilkan judul/nama sebuah karya.

  ```html
  <p><cite>Only for the Weak</cite> by In Flames</p>
  ```

- `<bdo>`: Untuk mengubah arah teks.

  ```html
  <p>Ini teks <bdo dir="ltr">normal</bdo></p>
  <p>Ini teks <bdo dir="rtl">terbalik</bdo></p>
  ```

  Atribut `dir` digunakan untuk mengubah arah penulisannya dan hanya menerima 2 nilai yaitu `ltr` (dari kiri ke kanan) dan `rtl` (dari kanan ke kiri).

## Elemen Link

Elemen link merupakan elemen yang digunakan untuk navigasi halaman, yaitu elemen `<a>`.

### Navigasi Antar Halaman

Kita bisa melakukan navigasi antar halaman dengan elemen `<a>` ini:

```html
<a href="index2.html">Pergi ke index 2</a>
```

### Navigasi Antar Elemen

Kita juga bisa melakukan navigasi di satu halaman, seperti pindah ke elemen lain.
Dengan cara:

Beri sebuah elemen atribut id:

```html
<h2 id="sejarah-html">Sejarah HTML</h2>
```

Lalu elemen `<a>` nya:

```html
<a href="#sejarah-html">Ke sejarah HTML</a>
```

Atau bisa juga dari halaman lain ke elemen spesifik:

```html
<a href="index.html#sejarah-html">Kembali ke sejarah HTML</a>
```
