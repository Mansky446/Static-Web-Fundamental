## Container

Di HTML ada beberapa elemen yang digunakan sebagai wadah dari elemen lain (container).
Dalam layouting kita biasanya membutuhkan pengelompokkan antar elemen.
Oleh karena itu, kita bisa menggunakan elemen container ini untuk mengelompokkan elemen-elemen di satu layout.

- `<div>` elemen untuk container besar bersifat block.
- `<span>` elemen untuk mengelompokkan paragraf/text.

## Button

Elemen untuk tombol.
Elemen ini memiliki atribut khusus seperti:

- `onclick` event apa yang dilakukan bila elemen `<button>` ditekan.
- `type` tipe button bernilai:
  - `submit` untuk submit form bila elemen ini berada didalam elemen `<form>`.
  - `reset` untuk mereset semua input bila elemen ini berada didalam elemen `<form>`.
  - `button` supaya elemen `<button>` saat ditekan melakukan event kustom yang sudah didefinisikan di atribut `onclick`.

Contoh penggunaan elemen `<button>`:

```html
<button type="button" onclick="alert('Hello World!')">Click Saya</button>
```

## Form

HTML memiliki elemen khusus untuk menampung input user yang bernama `<form>`.
Elemen tersebut digunakan sebagai wadah untuk menampung elemen-elemen input user seperti `<input>`, `select`, `<textarea>`, dll.
Nantinya nilai-nilai dari elemen tersebut akan dikumpulkan oleh elemen `<form>` dan dikirim bersamaan.

Elemen `<form>` memiliki atribut khusus seperti:

- `action` menyimpan kemana input dari user ini dikirimkan.
- `target` dimana response dari server diterima dengan nilai yang valid adalah:
  - `_blank` di tab baru.
  - `_self` di page yang sama (default).
- `method` metode pengiriman data ke server:
  - `get` menempel pada url nya.
  - `post` data dimasukkan kedalam http request body.

## Select

Elemen `<select>` digunakan untuk menampilkan pilihan dropdown.
Elemen `<option>` digunakan sebagai item dropdown.
Elemen `<optgroup>` digunakan untuk mengelompokkan item dropdown.

Atribut khusus di elemen `<select>`:

- `size` untuk memberitahu berapa banyak item dropdown yang ditampilkan.
- `multiple` agar item dropdown yang dipilih lebih dari satu.

Atribut khusus di elemen `<option>`:

- `value` nilai dari item dropdown tersebut.
- `selected` agar item dropdown tersebut menjadi item yang dipilih secara default.

Atribut khusus di elemen `<optgroup>`:

- `label` nama dari kelompok tersebut.

Contoh penggunaan elemen-elemen tersebut:

```html
<p>Aksi:</p>
<select>
    <optgroup label="Bermain">
        <option value="bermain_bola">Bermain Bola</option>
        <option value="bermain_gitar">Bermain Gitar</option>
        <option value="bermain_poker">Bermain Poker</option>
    </optgroup>
    <option value="bengong" selected>Bengong</option>
    <optgroup label="Mencuci">
        <option value="mencuci_piring">Mencuci Piring</option>
        <option value="mencuci_pakaian">Mencuci Pakaian</option>
    </optgroup>
    <option value="makan">Makan</option>
    <option value="minum">Minum</option>
</select>
```

## Textarea

Elemen `<textarea>` digunakan untuk tempat user menginput text yang panjang seperti catatan.
Adapun atribut khusus seperti:

- `cols` seberapa banyak kolom input dari user.
- `rows` seberapa banyak baris input dari user.
- `placeholder` untuk hint saat `<textarea>` masih kosong.

```html
<textarea cols="50" rows="3" placeholder="Catatan...">Nama saya tidak diketahui</textarea>
```

## Input

Elemen `<input>` digunakan sebagai tempat user memasukkan data di dalam sebuah halaman formulir.
Elemen `<input>` memiliki atribut khusus bernama `type`.
Atribut tersebut memberitahu bagaimana bentuk dan format data yang bisa di input oleh user.

### 1. Text

Untuk input user yang bertipe text umum seperti nama.

```html
<input type="text"/>
```

### 2. Email

Untuk input user yang bertipe text email.

```html
<input type="email"/>
```

### 3. Password

Untuk input user yang bertipe text password.

```html
<input type="password"/>
```

### 4. Tel

Untuk input user yang bertipe text nomor telpon.

```html
<input type="tel"/>
```

### 5. Url

Untuk input user yang bertipe text url.

```html
<input type="url"/>
```

### 6. File

Untuk input user yang bertipe file.

```html
<input type="file"/>
```

### 7. Color

Untuk input user yang bertipe warna yang akan menampilkan color picker.

```html
<input type="color"/>
```

### 8. Date

Untuk input user yang bertipe tanggal.
Bisa kita berikan batas `min` untuk tanggal minimal dan `max` untuk tanggal maksimal.

```html
<input type="date" max="2026-12-31" min="2026-01-01"/>
```

### 9. Hidden

Untuk input user yang tidak terlihat.

```html
<input type="hidden" value="secret"/>
```

### 10. Checkbox

Untuk input user yang opsional untuk dipilih.

```html
<input type="checkbox" id="remember-me"/>
<label for="remember-me">Remember Me</label>
```

### 11. Radio

Untuk input user yang opsional untuk dipilih.

```html
<input type="radio" name="gender" id="laki-laki"/>
<label for="laki-laki">Laki-laki</label>
<input type="radio" name="gender" id="perempuan"/>
<label for="perempuan">Perempuan</label>
```

## Label

Elemen ini bisa digunakan sebagai lebel untuk elemen-elemen input seperti `<select>`, `<textarea>` dan `<input>`.
Kita bisa menyambungkan `<label>` dengan elemen input dengan:

- `for` pada elemen `<label>` untuk menunjuk elemen mana yang ingin diberi label.
- `id` pada elemen input yang dituju.

```html
<label for="username">Username:</label>
<input id="username"/>
```

## Form Lanjutan

Pada elemen-elemen input seperti `<select>`, `<textarea>` dan `<input>` bisa diberikan atribut khusus agar datanya terbaca oleh `<form>`. Atribut tersebut yaitu `name`.

```html
<form action="" method="get">
    <label for="name">Username</label>
    <input type="text" name="name" id="name"/>
    <label for="name">Email</label>
    <input type="email" name="email" id="email">
    <button type="submit">Submit</button>
    <button type="reset">Reset</button>
</form>
```
