## Struktur Elemen HTML

### Elemen Berisi

```html
<h1 class="title">Ini Judul</h1>
```

Terdiri dari:

- `<h1 class="title">`: Tag pembuka
- `class="title"`: Atribut bernilai
- `Ini Judul`: Konten elemen
- `</h1>`: Tag penutup

### Elemen Tidak Berisi

```html
<input type="text" disabled>
```

- `<input type="text" disabled>`: Tag
- `type="text"`: Atribut bernilai
- `disabled`: Atribut tidak bernilai

## Atribut Elemen HTML

- Atribut elemen HTML memberikan informasi tambahan tentang elemen HTML tersebut.
- Semua elemen HTML bisa memiliki nol atau banyak atribut.
- Atribut elemen HTML selalu berada di tag pembuka.

Atribut elemen dibagi menjadi 2 berdasarkan bentuknya, yaitu:

### Atribut Bernilai

Atribut yang memiliki nilai.

```html
nama-atribut="nilai-atribut"
```

### Atribut Tidak Bernilai

Atribut yang tidak memiliki nilai. Bisa diberikan nilai, namun nilainya tidak berguna.
Karena di atribut tidak bernilai, yang penting adalah kehadiran atributnya.

```html
nama-atribut
```

## Hirarki Elemen HTML

```html
<!DOCTYPE html>
<html>
<head>
    <title>Ini Judul Halaman</title>
</head>
<body>
    <h1>Ini Judul</h1>
    <p>Ini paragraf.</p>
</body>
</html>
```

Hubungan antar elemen di HTML dapat berupa:

### Hubungan Bertingkat

Elemen HTML yang berada didalam elemen HTML lainnya yang biasa disebut elemen HTML bertingkat.

Elemen `<head>` dan `<body>` berada didalam elemen `<html>` yang berarti memiliki hubungan bertingkat.

Elemen `<html>` adalah kontainer, lalu elemen `<head>` dan `<body>` adalah isi.

### Hubungan Majemuk

Elemen HTML bisa juga berada disamping atau dibawah elemen HTML lainnya yang biasa disebut elemen HTML majemuk.

Elemen `<h1>` dan `<p>` memiliki hirarki yang sama, sehingga mereka memiliki hubungan majemuk (tetangga).

Elemen `<h1>` merupakan tetangga elemen `<p>`, begitu juga antara elemen `<head>` dan `<body>`

## Komentar

```html
<!-- Ini adalah komentar satu baris -->
<!-- Ini adalah
komentar dua baris -->
```

- Komentar adalah kode yang tidak akan ditampilkan oleh browser.
- Komentar hisa dijadikan sebagai penjelasan kode.
- Komentar dapat menjadi penanda mulai dan selesai elemen untuk elemen yang mempunyai konten panjang.

## Sistem URL

URL di HTML terbagi menjadi 2 jenis, yaitu:

### URL Absolut

URL yang menunjuk ke lokasi yang ada di internet atau website lain (eksternal),
sehingga membutuhkan koneksi internet untuk mengaksesnya.

```html
"https://www.w3schools.com/Html/html_intro.asp"
```

### URL Relatif

URL yang menunjuk ke lokasi internal.
Bila diawali dengan / maka lokasinya relatif ke root folder.
Sedangkan kalau tidak, akan relatif ke folder dimana file HTML tersebut berada.

```html
"logo-html5.png"
```

## Elemen HTML Dasar

```html
<!DOCTYPE html>
<html>
<head>
    <title>Ini Judul Halaman</title>
</head>
<body>
    <h1>Judul Utama</h1>
    <h2>Subjudul 1</h2>
    <h3>Subjudul 2</h3>
    <h4>Subjudul 3</h4>
    <h5>Subjudul 4</h5>
    <h6>Subjudul 5</h6>
    <p>Paragraf</p>
    <a href="https://www.w3schools.com/Html/html_intro.asp">Ini link</a>
    <br>
    <img src="logo-html5.png" alt="logo html5" width="120" height="60">
</body>
</html>
```

Penjelasan:

- `<h1>` - `<h6>`: Elemen untuk menampilkan judul.
- `<p>`: Elemen untuk menampilkan paragraf.
- `<a>`: Elemen untuk menampilkan link.
- `<br>`: Elemen untuk menampilkan spasi newline.
- `<img>`: Elemen untuk menampilkan gambar.
