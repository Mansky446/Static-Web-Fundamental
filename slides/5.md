## Box

Elemen HTML memiliki hirarki ruang yang jelas. Diantaranya adalah:

- `content`: Konten dari elemen
- `margin`: Jarak antara konten dengan border
- `border`: Border untuk elemen
- `padding`: Jarak antara border dengan keluar

## Default Display

Setiap elemen HTML memiliki display default dengn nilai tergantung jenis elemennya.
Ada 3 display yang biasanya tertanam pada elemen-elemen sebagai default.

### 1. Display Block

Display yang selalu dimulai dengan baris baru dan mengambil width parent secara keseluruhan.
Contoh elemen dengan display default block:

- `<div>`
- `<p>`
- `<table>`
- `<adress>`
- `<blockquote>`

Elemen yang display-nya block dapat diatur ukuran, margin serta padding-nya.

### 2. Display Inline

Display yang mengambil ukuran hanya seukuran kontennya saja.
Contoh elemen dengan display default inline:

- `<a>`
- `<i>`
- `<bold>`
- `<span>`

### 2. Display Inline Block

Display yang mengambil ukuran hanya seukuran kontennya saja pada awalnya, namun ukurannya dpat di kustomisasi.
Contoh elemen dengan display default inline block:

- `<img>`
- `<input>`
- `<button>`

Elemen ini dapat diatur ukuran, margin dan padding-nya namun tanpa mengambil keseluruhan lebar dari parent-nya.

## Display Lain

### 1. Display Flex

Display yang dimana posisi dan ukuran childnya bisa diatur secara fleksible.
Display ini bertujuan untuk mengatur layout linear.

### 2. Display Grid

Sama seperti display flex, namun grid ini dapat mengatur layout secara 2 arah, vertikal dan horizontal.

## Ukuran Elemen

Ukuran elemen di HTML menunjuk ke ukuran elemen tersebut di sistem layoutnya.
Ukuran HTML bisa diubah secara konstan dengan mengubah properti `width` dan `height` ataupun secara otomatis diatur oleh parent.

Adapun properti yang berpengaruh terhadap apa yang diatur oleh `width` dan `height`, yaitu `box-sizing`.

- `box-sizing: border-box;`: Mengatur ukuran sampai ke level border
- `box-sizing: context-box;`: Mengatur ukuran hanya di level konnten
